# Frontend Vue.js — Rumo Premium

SPA Vue 3 via CDN (sem Node/build).

**Fonte da verdade:** pasta `frontend/`.  
No build Maven (`generate-resources`), o conteúdo é copiado para `src/main/resources/static/` (exceto este README), mantendo o HTML/CSS/JS servido pelo Spring alinhado à fonte.

## Acesso

Com a API em execução: http://localhost:8080/

## Funcionalidades

- Criação de aluno (assinatura BASICA)
- Registro de conclusão de curso
- Barra de progresso (X/12), assinatura e moedas
- Estados de loading, erro e lista vazia
